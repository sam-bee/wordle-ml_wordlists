# Wordle ML - Wordlists

Part of the Wordle ML project. These wordlists represent 5-letter words that you are allowed to play in a Wordle game
(valid guessts), and words that are allowed to be the correct answer (valid solutions).

## Number of Words

- 12,946 valid guesses
- 2,308 valid solutions

The solutions are a subset of the guesses.

## Format

Words should be in block capitals throughout the project.
